Este é um protótipo PWA.
Para instalar:
1. Hospede os arquivos em um servidor HTTPS (GitHub Pages, Netlify, Vercel).
2. Abra no Chrome/Edge do celular.
3. Toque em 'Adicionar à tela inicial'.

Para um app Android/iPhone publicado, é necessário desenvolver em Flutter ou React Native e gerar APK/AAB e IPA.
